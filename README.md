# 校级实验室业务管理平台 · 管理端静态演示（animal-lab-demo）

供客户演示与业务确认的管理端静态交互 Demo。**只做管理端**，不含普通用户使用端；所有数据为本地模拟，不连接任何后端或真实学校接口。

## 运行环境

- Node.js ≥ 20，npm ≥ 10
- 端口默认 4173（`vite preview`），如被占用可改用 `npm run preview -- --port 其他端口`

## 常用命令

```bash
npm ci          # 从锁文件安装依赖
npm run dev     # 开发模式（默认 5173）
npm run build   # 类型检查 + 生产构建 → dist/
npm run build:single  # 额外把 JS/CSS 内联进 dist/index.html（可双击打开的单文件版）
npm run preview # 预览构建产物 http://localhost:4173/
npm run test    # Vitest 自动化业务测试（20 条）
```

浏览器冒烟与演示主线走查脚本（需本机可用 Playwright Chromium）：

```bash
npm run preview &
node tests/smoke.mjs http://localhost:4173/   # 遍历页面截图 + 控制台错误检查
node tests/flow.mjs  http://localhost:4173/   # 内部订单出库→扣费成功→饲养计费→恢复数据
```

## 数据与恢复

- 数据保存在浏览器 `localStorage`（key：`lab-demo-state`），刷新保留；种子版本变更自动重置。
- 顶栏「恢复演示数据」一键回到初始种子场景，可反复演示。
- 全部业务围绕两个实验室（实验动物中心 / 分析测试中心）隔离，所有实体带稳定 ID 与 `labId`。

## 目录结构

```
src/
  core/          状态容器、种子数据、权限、数据访问、业务操作（orders/stock/purchase/feeding/fee/system）
  core/schoolapi.ts   学校扣费接口的模拟适配层（替换真实实现只改这一个文件）
  pages/         12 个页面（概览/服务/订单/库存/采购/饲养/笼位/费用/菜单/角色/用户/登录）
  ui/            按《部门后管界面规范 v0.25》实现的表格/分页/弹窗/表单组件
  styles/        设计令牌与基础样式
  tests/         Vitest 业务规则测试 + Playwright 冒烟/走查脚本
docs/            页面与权限清单、演示假设、演示脚本、自测报告、阶段记录、截图
```

## 交付与限制说明

- 交付物包含源码、锁文件、`dist/` 构建产物、自动化测试、文档与截图，详见 `docs/`。
- 学校扣费为**本地 mock**：成功流水带 `SCH-DEMO` 前缀，不代表学校真实扣费成功。
- 前端本地隔离只用于演示，不等于生产环境的安全验收。
- 详细业务边界与演示假设见 `docs/演示假设与待确认.md`。
