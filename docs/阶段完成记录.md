# 阶段完成记录

对应《01_分阶段实现要求.md》。技术栈偏离说明：按最近一次会话的既定方向，工程使用 **原生 TypeScript + Vite**（无 Vue/Element Plus），组件层按《部门后管界面规范 v0.25》自实现（`src/ui/`），hash 路由，构建产物可静态托管。其余业务边界与执行包一致。

## 阶段 0：工程与实现计划 ✅

- 独立工程 `animal-lab-demo/`，依赖：typescript、vite、vitest（锁文件已提交）。
- 版本化种子数据（`SEED_VERSION = 2`）：两个实验室、6 个演示账号、服务/订单/库存/供应商/客户/笼位/饲养/费用/扣费请求/项目全量实体。
- 统一工具：金额按分（`formatMoney/parseYuan`）、日期字符串与区间天数（开始含、结束不含）、稳定 ID、CSV 导出。
- 学校扣费模拟适配层独立文件 `src/core/schoolapi.ts`。

## 阶段 1：框架与权限 ✅

- 顶栏（实验室切换、全校视图、身份、恢复数据）+ 左侧角色授权菜单。
- 菜单/角色/用户三项基础管理；菜单树形授权；保护角色不可删停。
- 数据范围过滤 `scoped()` + 写操作二次校验实体归属；路由守卫 + 操作权限标识。
- 自测 T01—T08 通过（见自测报告）。

## 阶段 2：服务与统一订单 ✅

- 服务管理：新增编辑、上下架、价格、三种审核方式；下架不影响已有订单。
- 订单管理：统一列表 + 类型页签、筛选重置分页、详情与历史、审核确认/退回（原因必填）、代录外部客户订单。
- 按类型显示动作：内部出库、外购确认金额/生成费用、饲养入场。
- 自测 T09—T13 通过。

## 阶段 3：内部库存与外购需求 ✅

- 动物/耗材库存、入库、业务出库、带原因的盘点调整；唯一流水。
- 内部订单整单出库联动：库存扣减 → 订单完成 → 自动生成费用；重复出库幂等。
- 供应商维护、按供应商汇总批次、CSV 导出、标记已发送（幂等）、异常代登记与跟进。
- 自测 T14—T20 通过。

## 阶段 4：饲养、笼位及耗材 ✅

- 入场（校验空闲/停用/跨实验室/重复）、笼位增减（生效日期 + 原因）、退出（释放并保留历史）。
- 关联饲养单的耗材领用：扣一次库存、当日同单同品同量防重复点击。
- 区间计费依据：占用切段计算，为阶段 5 提供计费口径。
- 自测 T21—T25 通过。

## 阶段 5：模拟学校扣费 ✅

- 费用明细（内部/外购/饲养三类来源）、提交扣费、结果查询、失败重试、尝试记录。
- 幂等：业务标识按费用 ID 固定；processing/成功禁止重复提交；unknown 保持处理中可反复查询。
- 演示结果控件（成功/失败/暂未知）标注为模拟；外部客户订单「外部结算待确认」。
- 自测 T26—T33 通过。

## 阶段 6：整体验收与交付 ✅

- 业务概览（指标卡 + 最近订单，点击进入筛选列表）。
- 自动化测试 20 条（`npm run test`），浏览器冒烟（12 页面截图 + 控制台零错误）与演示主线走查脚本（`tests/smoke.mjs`、`tests/flow.mjs`）。
- 交付目录：`dist/`、`README.md`、`docs/`（页面权限、演示假设、演示脚本、自测报告、截图）。

## 遗留事项

- Playwright 依赖未写入 `package.json`（冒烟脚本引用本机 npx 缓存），如需在其他机器运行请 `npm i -D playwright`。
- 服务大厅审批仅提供模拟通过/退回结果，无流程设计器（范围外）。
- 移动端、真实学校接口、生产部署不在本轮范围。
