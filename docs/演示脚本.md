# 演示脚本（可照做，每步含预期结果）

前置：`npm run preview` 打开 `http://localhost:4173/`。任何时刻可点 PC 顶栏右侧「重置数据」重来。

## 0. 开场与身份隔离（对应演示要点 1）

1. 打开首页 → 出现登录页，选择**王超管（超级管理员）**进入。
   预期：左侧出现全部菜单，含「平台基础」；顶栏有「全校视图（只读）」开关和实验室切换。
2. 勾选「全校视图」→ 任意页面点「新增服务」等写按钮。
   预期：提示「全校视图为只读汇总，处理业务请先选定实验室」，数据不变。
3. 切换身份为**李动物（动物中心管理员）**。
   预期：无「平台基础」菜单；直接在地址栏构造 `#/system/user` → 显示「无权限访问」。
4. 切换身份为**周双中（双中心管理员）**，顶部切换到「分析测试中心」。
   预期：列表只显示分析中心数据（品目 KM 小鼠数量为 120 而非动物中心数据）；切回动物中心数据不同。

## 1. 内部动物订购主线（对应演示要点 2）

1. 身份：李动物。订单管理 → 找到 **AD-ORD-0001**（待确认，KM 小鼠 30 只）→ 点「确认通过」。
   预期：审核状态「已通过」，履约状态仍「待出库」（审核通过 ≠ 完成）。
2. 点「整单出库」。
   预期：提示出库成功；订单状态「已完成」；toast 显示已生成费用 ¥1,350.00。
3. 库存管理 → KM 小鼠行。
   预期：库存由 120 变为 **90**，库存流水中有一条「订单 AD-ORD-0001 整单出库 -30」。
4. 回到订单管理再次观察该订单（或重复点击出库的防御逻辑）。
   预期：重复出库被拒绝，库存不变。
5. 费用结算 → AD-ORD-0001 费用行 → 「提交扣费」→ 选经费项目 → 确认提交。
   预期：状态「扣费处理中」。
6. 点「查询结果」（演示结果控件默认「扣费成功」）。
   预期：状态「扣费成功」，出现学校模拟流水 `SCH-DEMO-xxxxx`；再次「提交扣费」被拒绝。
7. 尝试 **AD-ORD-0003**（SD 大鼠 60 只，库存 20）点「整单出库」。
   预期：提示「库存不足」，台账不变。

## 2. 库存类别与损耗登记（库存管理演示）

1. 库存管理 → 品目台账 → 类别筛选选「维修配件」→ 查询。
   预期：空表提示；说明类别是校级预置档案，螺丝钉这类新物资只需建档时选择对应类别，不需要改系统。
2. 「新增物资建档」→ 类别「维修配件」→ 名称「不锈钢螺丝钉」→ 规格「M4×20」→ 单位「盒」→ 安全库存填 5 → 确认。
   预期：建档成功，可立即办理入库；弹窗顶部说明「首次使用可批量导入现有台账，日常仅新物资需要建档」。
3. 在 KM 小鼠行点「损耗」（或工具栏「损耗登记」）→ 品目已自动预选并锁定。
   预期：原因下拉自动出现「死亡 / 淘汰」；改选饲料类品目，原因切换为「过期 / 损坏 / 丢失」——原因选项随类别档案提供。实际演示时说明：动物死亡、耗材过期损坏都是「发生即登记」，盘点只兜底。
4. 选 KM 小鼠、数量 3、原因「死亡」→ 确认登记。
   预期：库存 120 → 117；库存流水出现红色「损耗 -3」记录，含变更前后与原因；费用结算无任何新增费用。
5. 打开「盘点调整」弹窗看提示。
   预期：提示「日常死亡/损耗请先走损耗登记，盘点只处理差异」，且不能调整为负库存。
6. 「入库登记」→ 查看字段：库存品目、入库数量、**入库日期（默认今天）**、**来源类型（中心自产/供应商到货/调拨/其他）**、**供应商**、来源/原因 → 选 KM 小鼠、数量 10、来源类型「供应商到货」（切换后供应商下拉才可用）、供应商选「实验小鼠｜维通利华」、来源「供应商送货」→ 确认。
   预期：库存 117 → 127；库存流水日期为所选日期，原因列显示「供应商送货（北京维通利华实验动物技术有限公司·KM小鼠）」。
7. 「批量导入」→ 「下载导入模板（CSV）」→ 模板已填充 3 行示例（BALB/c小鼠、辐照灭菌垫料、六角螺栓）→ 用 Excel 另存 CSV 或直接使用 → 选择文件 → 「开始导入」。
   预期：提示「成功 3 条」；台账出现 3 个新品目，BALB/c小鼠期初 100 只、六角螺栓 30 盒；库存流水自动生成 3 条「期初库存导入」。
8. 点「只看预警品目」。
   预期：只显示**裸鼠（NU/NU）3/10 只**、**高脂造模饲料 8/30 kg** 两条，状态为「低于安全库存」；再点「显示全部库存」恢复。
9. 切「库存流水」→ 日期字段默认近一周（开始 ~ 结束合并为一个字段），可改成今天；种子里已含入库/出库/损耗/盘点四类流水；类型选「损耗」→ 查询；顶部看汇总「共 N 条 · 入库合计 · 出库合计 · 损耗合计」；点「导出 CSV」下载；出库行点「查看订单 AD-ORD-0021」直接打开对应订单详情。
   预期：日期/类型筛选只留今天损耗行；流水日期精确到秒（如 2026-11-10 21:40:05）；汇总数字与列表一致；导出文件名「库存流水.csv」；订单详情标题为 AD-ORD-0001（第一部分出库的那一单）。

## 3. 外购主线（对应演示要点 3）

0. 服务管理：新增/编辑服务时字段随类型切换——自产动物显示库存品目；外购动物显示供应商+供应条目（不显示库存品目，规格/单位/价格选条目后自动带出）；饲养寄养两者都不显示。说明外购动物无库存、不入库。
0.1 供应商管理（独立菜单）→ 5 家供应商；「新增供应商」可同时添加多条供应条目（动物品系/物资品种，编码 SI-0001 起系统生成，名称可重复）；行内「供应条目」可新增/编辑/停用条目；停用供应商后不再出现在服务与汇总选择中。

1. 订单管理 → **AD-ORD-0005**「确认通过」。
2. 外购汇总（菜单）→ 未处理页签：**每个供应商一栏**，栏内按品系合并数量（一行一个品系：品系、规格、单位、数量合计、单价、金额、来源订单数）。
   预期：种子含 3 家供应商——维通利华（C57BL/6J 15 只、KM小鼠 30 只、SD大鼠 15 只）、川黔（SD大鼠区域现货 6 只）、斯贝福（BALB/c裸鼠 3 只）；同一品系多个订单合并一行；已发送订单只在「已处理」页签。
3. 供应商栏「明细」查看来源订单（谁订的、各自多少只）；点品系行的「来源订单数」可看该品系的来源订单；弹窗内点「详情」打开订单详情（审核、金额、历史）；弹窗已加宽便于核对 →「导出 CSV」（或顶部「导出未处理清单」）。
   预期：导出的是品系汇总表（供应商、品系、规格、单位、数量、单价、金额）；文件名「外购未处理清单_日期.csv」。
4. 供应商栏「标记已处理」→ 切换到「已处理」页签。
   预期：该供应商这批订单变为「已处理（已发供应商）」；未处理页签不再出现；**没有**「到货入库」「交付完成」类操作。
5. 订单管理 → 「外购动物」页签：发送状态列区分未发送/已发送，可按「发送状态」筛选；列表含单价/金额列，可导出当前列表。
   预期：导出文件名「外购订单清单_日期.csv」。异常跟进本轮暂不开放。

## 4. 饲养主线（时空排位预分配、2天保留释放、现场入住与消杀治理）

1. **时空排位与48小时保留预分配**：
   - 饲养管理 → 待入场 → 找到 **AD-ORD-0009**（学生·孙同学，拟申办 2 笼 IVC 小鼠位，状态「待排位审核」）→ 点击「审核排位预分配」。
   - 弹窗展示「拟入场日期」与「拟饲养天数」，系统自动根据时空重叠公式实时剔除冲突笼位，并自动推导「保留至拟入场日+2天（48小时）23:59」。
   - 勾选同一机架的 **A-103、A-104** → 点击「审核通过并锁定排位」。
   - 预期：订单状态变为「已预分配·待入住」，锁定笼号 A-103、A-104；对应物理笼位进入黄色 `reserved` 预分配锁定状态。
2. **48小时保留期现场直接核验入住**：
   - 在待入场列表中，观察 **AD-ORD-0015**（学生·赵同学，已提前排位锁定 A-109、A-110，保留截止倒计时生效中）→ 点击「办理现场入住」。
   - 弹窗严格按原申请执行，直接带出已锁定笼号；一键点击「确认办理入住」。
   - 预期：无需现场重新选笼，物理笼位由预锁定黄色 `reserved` 正式转正为绿色 `occupied`；真实 Day 1 确立，系统自动划扣项目预付基础饲养费 ¥400.00，订单流转进入在养监控池。
3. **2天超期未到自动释放与待重新排位**：
   - 观察待入场列表中的 **AD-ORD-0016**（学生·钱同学，拟入场日超期 2 天未到校办理）。
   - 预期：订单状态被打上红色「逾期释放·待重排」标签，其原锁定的物理笼位已由系统自动释放回空闲池 `free` 供他人使用；操作列提供「重新排位预分配」入口。
   - 点击工具栏「🔄 检查逾期保留释放」按钮，触发全局逾期检测引擎，并在日志中留下可追溯的自动流转审计。
4. **空间看板网格联动与消杀流转**：
   - 点击顶部或工具栏「笼位空间看板」进入 `/cage/board`。
   - 观察 101 室机架网格：黄色代表预分配锁定、绿色代表在养占用、红色代表停用检修、深蓝代表消杀熏蒸中。
   - 找到消杀中的 **A-108**（合笼归并释放的终末消杀笼位），点击查看详情抽屉，并点击「完成消杀（恢复空闲）」。
   - 预期：A-108 笼位立即恢复为绿色空闲 `free`，可供后续实验排位申请。
5. **在养管理与合笼释放**：
   - 回到饲养管理 → 在养监控列表 → 找到在养记录点击「笼位变更」。
   - 选择合笼释放（减少 1 笼）并填写变更原因 → 保存。
   - 预期：在养占用数 -1，释放的笼位自动流转进入蓝色待消杀池 `cleaning`，期初预付款不退并线下补发饲料平衡。
6. **耗材领用与退出计费**：
   - 「耗材领用」→ 选维持饲料 5kg → 确认。预期：库存扣 5，流水一条；重复点击提示已登记，不再扣减。
   - 「退出」→ 确认退出。预期：笼位释放为空闲，历史占用保留，状态「已退出」。
   - 对 **AD-ORD-0011**（已退出）点「区间计费」→ 试算显示分段阶梯计费，生成后防重复。

## 5. 学校扣费异常场景（对应演示要点 5）

1. 费用结算 → AD-ORD-0013 费用行（初始为「扣费失败」）→「重试」。
   预期：进入处理中，可继续查询；尝试记录保留每次提交与结果。
2. 把「接口调试选项」切到「结果暂未知」→ 对一笔新费用提交后点「查询结果」。
   预期：保持「处理中」；重复「提交扣费」被拒绝；刷新页面后原请求仍在，可继续查询。
3. 切到「明确失败」→ 查询 → 状态「扣费失败」并显示原因；再切「成功」重试 → 最终只有一笔成功扣费。
4. 切身份为**赵财务（财务人员）**。
   预期：菜单只有概览／订单／费用；外购费用行显示「外部结算待确认」且无「提交扣费」入口。

3. PC 顶栏右侧「重置数据」→ 确定重置。
   预期：全部台账、授权、订单、费用回到初始种子场景，可重新完整演示。
